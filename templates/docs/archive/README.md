# docs/archive/ —— 历史的家（append-only）

规矩三条（详见 PLAYBOOK §二/§三）：

1. **归档 ≠ 删除**：进来的内容原文保留、编号不动；要取代其中结论，去 live 文档新增条目注明取代关系，这里的原文不改。
2. **只进不改**：本目录所有文件 append-only；轮转是"追加进来"，不是"整理重写"。
3. **按需 grep、不通读**：这里是抽屉不是桌面。agent 与人都应该带着编号（D 号 / T 号 / 阶段名）来定点查。

本目录会随项目出现：`PROGRESS-status-log.md`（状态行流水）、`PROGRESS-stage-log.md`（阶段流水）、`PROGRESS-tasks-closed.md`（已关账任务行）、`PROGRESS-runtime-log.md`（待验更新流水）、`DECISIONS-D001-D100.md` 等（决策百段档）。
